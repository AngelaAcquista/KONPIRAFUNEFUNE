# KONPIRAFUNEFUNE
Konpira Fune Fune is a traditional Japanese drinking game played by Maiko and Geisha with their clients at tea houses. They sing a traditional Japanese song when playing the games. In our program, you are able to learn about this game and Japanese culture behind this game. You also play as the client against Geisha. Come check it out!

## How to Run This Game Using CMake
1. Open a command prompt or a terminal

2. Create a directory for this game using `git clone` as follows, or navigate to the pre-existing directory
	```
	git clone https://github.com/AngelaAcquista/KONPIRAFUNEFUNE.git
	```

3. Create a build directory and navigate into it
	```
	mkdir build
	cd build
	```

4. Run CMake to generate build files
	```
	cmake ..
	```

5. Build the project
	```
	cmake --build .
	```

6. Run the game
	```
	./FINAL.exe	```
